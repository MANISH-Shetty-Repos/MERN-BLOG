#  MERN Blog Application

A **full-stack blog platform** built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)** with **Tailwind CSS** for responsive styling.
The application follows the **MVC architecture** and supports complete **CRUD operations** with secure authentication.

##  Project Overview

The MERN Blog Application allows users to **create, edit, publish, and manage blog posts** through an intuitive and responsive interface.
It is designed to demonstrate **end-to-end full-stack development**, including frontend UI, backend APIs, database integration, and authentication.

This project emphasizes:

* Clean separation of concerns using MVC
* Secure user authentication
* Scalable REST API design
* Modern frontend practices



##  Key Features

*  **User Authentication**

  * Secure login & registration using Firebase Authentication
*  **CRUD Operations**

  * Create, Read, Update, and Delete blog posts
*  **MVC Architecture**

  * Clear separation between controllers, services, and routes
*  **Responsive UI**

  * Modern, mobile-friendly interface using Tailwind CSS
*  **RESTful APIs**

  * Well-structured APIs using Express.js
*  **Fast & Scalable Backend**

  * Node.js runtime with MongoDB database
